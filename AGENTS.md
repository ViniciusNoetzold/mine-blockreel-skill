# BlockReel project instructions

When asked to make a BlockReel film in this checkout, read `plugin/skills/blockreel/SKILL.md` first. Follow `docs/CINEMATIC-WORKFLOW.md` for a cinematic film or a showcase. Read `DIRECTOR.md` and `TECHNIQUE.md` before building. The storyboard schema is in `docs/STORYBOARD.md`.

Never commit game assets. Run `python -m pytest tests -q` after changing anything in `core/`.
