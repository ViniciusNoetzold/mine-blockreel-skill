# BlockReel project instructions

For a construction timelapse, including a building reconstructed from photos, start with `plugin/skills/blockreel-builds/SKILL.md`. For other BlockReel films, start with `plugin/skills/blockreel/SKILL.md`. Follow `docs/CINEMATIC-WORKFLOW.md` for a cinematic film or a showcase. Read `DIRECTOR.md` and `TECHNIQUE.md` before building. The storyboard schema is in `docs/STORYBOARD.md`.

Never commit game assets. Run `python -m pytest tests -q` after changing anything in `core/`.
