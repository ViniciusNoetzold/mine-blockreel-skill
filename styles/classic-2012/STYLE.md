# classic-2012

The bright, bouncy look of fan animations from the blocky-hype era.

| | |
|---|---|
| Sky | saturated blue to pale horizon, drifting white box clouds |
| Light | strong warm sun, hard shadows, high ambient so nothing is ever black |
| Camera | fov 62, fast dollies, close-ups at fov 40-48 |
| Cuts | every 2-3 s, hard cuts |
| Text | chat-style subtitles, 1-3 word title cards |
| Music | upbeat, bouncy, 110-130 bpm |
| Good for | comedy, adventure, parody, "noob vs pro" |

Avoid: letterbox, vignette, slow fades. Keep movement big and silhouettes readable.
