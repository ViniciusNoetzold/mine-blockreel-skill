# ember-haze

Warm red-magenta smoke haze: the aftermath palette. Use it only for the epilogue so the warm shift reads as a chapter change.
Derived from `references/video-analysis/673z48KEXy0.md` (the only warm palette in the reference film comes last).

| | |
|---|---|
| Sky | muted plum to dusty orange, no clouds |
| Light | warm low sun, high warm ambient, short fog (8–45) as smoke |
| Camera | fov 48, one slow push or a locked-off shot, shake near 0 |
| Cuts | very few; hold 5+ seconds |
| Palette partners | `bricks`, `cobble`, `tnt`, `glowstone`, `wool_red` |
| Good for | aftermath, epilogue, "what's left" |

Use `fx` kinds `smoke` and `fire` (continuous with `dur`); keep the camera still and let the particles move.
