# nightfall

Cold blue night with thick fog. Suspense and horror.

| | |
|---|---|
| Sky | near-black to deep blue, no clouds |
| Light | dim moonlight, low ambient, tight fog (10-55) so the world ends in darkness |
| Camera | fov 55, low angles, slow creeping dollies, shake only on scares |
| Cuts | irregular; long holds then sudden cuts |
| Music | drones, sparse notes, silence before the scare |
| Good for | mysteries, "don't go in there", survival |

Add `glowstone` or `tnt` blocks as light sources in the frame to guide the eye.
