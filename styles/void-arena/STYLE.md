# void-arena

Violet star-field void over pale ground. The final-showdown look: a cool-lit character against a bright floor.
Derived from the palette principles in `references/video-analysis/673z48KEXy0.md` (one palette per location).

| | |
|---|---|
| Sky | near-black violet to deep purple, no clouds |
| Light | cool lavender key from low behind-left, high ambient so pale ground reads bright |
| Camera | fov 50, low angles, handheld shake on every action shot (0.03–0.06) |
| Cuts | fast in action (1–2 s), hold on the quiet beat |
| Palette partners | build the floor from `sand` or `snow`, pillars from `obsidian`, a `glowstone` or `diamond` landmark |
| Good for | duels, finales, "boss fight" |

Pair with `ember-haze` as the epilogue palette to mark the act break.

Turn on `post: { bloom }` and give the villain `eyes: glow`; add `fx` sparks. A star-field sky is not implemented (the sky is a gradient).
