# Texture pack demo: "Pastel Meadow"

An original 16x block set (CC0), generated by code. 25 textures: terrain, wood, stone, bricks, metals, TNT, glass, animated water and lava, and two items.

| File | What |
|---|---|
| `make_textures.py` | the generator: one palette plan (4-tone ramps), tileable noise, wrapping cells, planks, bricks, bevels, animated strips |
| `textures/` | its 16x output, in the game's folder layout (`block/`, `item/`, `.png.mcmeta` for water and lava) |
| `pack.png` | the pack icon (2x2 collage) |
| `set-sheet.png` | the contact sheet from `tilecheck set` |
| `tiling/*.png` | 2x2 and 3x3 tiling previews of grass, stone, cobblestone, planks and sand |
| `preview-in-scene.png` | the pack rendered in a mini-world by the film engine |

```bash
python examples/texture-pack-demo/make_textures.py out/tex --res 16 --icon out/pack.png   # also --res 32 and --res 64
python core/tilecheck.py set out/tex --out out/report            # PROBLEMS and notes + contact sheet
python core/tilecheck.py check out/tex/block/stone.png --out out/stone_tiles.png
python tools/pack_preview.py out/tex --out out/preview.png       # in a scene, with a character for scale
python core/pack.py build out/tex --name "Pastel Meadow" --pack-format 46 \
  --format-version 1.21.4 --format-source https://minecraft.wiki/w/Pack_format --icon out/pack.png --out out/build
```

## Pack format (researched, not guessed)

**46 = resource pack format for Java 1.21.4**, read from the version table on [Minecraft Wiki: Pack format](https://minecraft.wiki/w/Pack_format)
(the same table lists 1.21.5 = 55, 1.21.6 = 63, 1.21.7-1.21.8 = 64). The wiki says that since 25w31a (Java 1.21.9) packs use `min_format` / `max_format` instead of
`pack_format`; build with `--min-format N --max-format M` for those versions. Versions listed with a decimal number (e.g. 97.1) are not supported by `core/pack.py`
because I could not confirm how to write them in `pack.mcmeta`. The number and its source are recorded in the pack's own `README.txt`.

## Review log

| Round | What I saw | Fix |
|---|---|---|
| 1 (contact sheet) | coherent pastel set; **cobblestone** had a few huge cells and read as cracked stone; **white wool** was dirty with noise | 13 cells with thin borders; lower noise and lighter bias for wool |
| 1 (tiling 3x3) | grass, stone, cobblestone and planks repeat without visible seams | none |
| 2 (in scene) | grass does not show a repeating grid on large surfaces; grass top and side match; glass, water and lava read well next to the character; **leaves** looked like a solid green cube | more holes in the leaves |
| tool check | the seam detector flagged bricks and the bevelled gold/diamond blocks | fixed the detector (compare with the worst interior boundary; bordered blocks are reported as notes), see `core/tilecheck.py` |

`tilecheck set` result: no PROBLEMS at 16x, 32x or 64x. Notes only: gold block, diamond block and grass side have a border by design.
